# 素材库交付规范

这份规范的目的：让你放进来的素材能被录入流水线**直接吃进来**，不用二次返工。
请优先保证下面「★ 最高价值的四样东西」齐全——它们直接决定题库质量的上限。

---

## 目录结构

```
materials/
├─ README.md            # 本文件
├─ MANIFEST.csv         # 试卷清单（每套卷登记一行，务必填）
├─ papers/              # ★ 真题试卷（核心）
│   ├─ _TEMPLATE/       # 单套卷的目录模板，照着复制
│   └─ 2023-XX大学-高等数学A上-期中/
│       ├─ paper.pdf            # 空白试卷（必需）
│       ├─ answers.pdf          # 答案 / 解析（★ 有就一定要放）
│       ├─ filled/              # 手写答卷、批改后的卷子（如有）
│       └─ meta.md              # 该卷元信息（照 _TEMPLATE/meta.md 填）
├─ syllabus/            # ★ 教学大纲 / 教材目录 / 考试范围说明
├─ textbook/            # 教材、讲义、课件、老师划的重点
└─ notes/               # 平时作业题、例题、你自己的错题集
```

## ★ 最高价值的四样东西（按重要性排序）

| 排序 | 素材 | 为什么关键 | 缺失的后果 |
|---|---|---|---|
| 1 | **真题试卷 + 配套答案/解析** | 真题演练的命脉。有官方答案才能自动判分、才能作为 AI 出题的校准基准 | 只能靠 AI 自己解题，误差大且无法验证 |
| 2 | **教学大纲 / 教材目录 / 考试范围说明** | 定义了"阶段性测试"到底考到哪。**不同学校高数上/下的章节划分和进度都不一样** | 出题范围会偏，超纲或漏考 |
| 3 | **老师划的重点、平时作业、课堂例题** | 最贴近真实考点的信号，比任何通用题库都准 | 出题偏"通用考研风"，不贴合你们学校的阶段测 |
| 4 | **手写答卷 / 批改过的卷子** | 能反推评分标准、得分点、常见失分处 | 解答题 AI 判分的 rubric 只能靠猜 |

## 试卷目录命名规范

```
YYYY-来源-科目-阶段
```

示例：
- `2023-XX大学-高等数学A上-期中`
- `2024-XX大学-高等数学B下-阶段测2`
- `2022-XX学院-高数上-期末`

同一份卷有 A/B 卷或多个班级版本时，分开建目录：
`2023-XX大学-高等数学A上-期中-A卷` / `...-B卷`

## 扫描件质量要求（针对 PDF / 图片）

| 项 | 要求 |
|---|---|
| 分辨率 | **≥ 300 dpi**，公式密集处尽量 400 dpi |
| 拍摄角度 | 正射。不要倾斜、不要透视变形（拍歪了公式下标会识别错） |
| 光线 | 均匀，避免阴影、反光、手指遮挡 |
| 页序 | **必须正确**，多页可合并为一个 PDF，也可逐页图片 |
| 手写内容 | **空白卷和手写答卷分开放**（`paper.pdf` 必须干净无手写） |
| 格式 | PDF 优先；图片用 PNG/JPG（不要用 HEIC、不要用微信压缩过的图） |

> 公式 OCR **一定会有错**，录完我会做人工校对。你的扫描质量直接决定校对工作量：
> 300dpi 正射扫描件大概 95%+ 可直接用，歪斜的手机翻拍可能只有 70%。

## `meta.md` 需要填写的信息

每套卷目录里放一份。这些字段直接对应系统的 `Paper` 数据模型：

```markdown
# 试卷元信息

- 来源 / 学校：
- 年份：
- 考试类型：期中 / 期末 / 阶段测N / 模拟
- 适用科目：高等数学A上 / A下 / B上 / B下 …
- 考试范围（章节）：
- 总分：100
- 时长（分钟）：120
- 题目结构：
  | 题号 | 题型 | 题数 | 每题分值 |
  |---|---|---|---|
  | 一 | 单项选择题 | 5 | 4 |
  | 二 | 填空题 | 5 | 4 |
  | 三 | 计算题 | 6 | 8 |
  | 四 | 证明题 | 2 | 8 |
- 是否有答案：是 / 否
- 是否有解析：是 / 否
- 扫描质量备注：
```

> **题目分值**很关键。如果卷面上没印分值，请在这里给出你的推定，或标注"未知"，我会按常规模式推定后请你确认。

## MANIFEST.csv 怎么填

每套卷登记一行。列说明：

| 列 | 说明 |
|---|---|
| `dir` | `papers/` 下的目录名，如 `2023-XX大学-高等数学A上-期中` |
| `year` | 年份 |
| `school` | 学校 / 来源 |
| `exam_type` | 期中 / 期末 / 阶段测1 / 模拟 |
| `course` | 高等数学A上 等 |
| `chapters` | 覆盖章节，如 `C1-C5` |
| `total_score` | 总分 |
| `duration_min` | 时长（分钟） |
| `has_answer` | 是 / 否 |
| `has_solution` | 是 / 否 |
| `scan_quality` | 好 / 中 / 差 |
| `note` | 备注 |

## 开始录料之前，请先告诉我三件事

1. **素材类型**：`syllabus/` 里的考试范围，是按你们学校教学大纲界定，还是按教材章节界定？
2. **答案情况**：真题**是否配备官方答案/解析**？大概几成有？
3. **规模**：总共大概多少套卷？先给几套让我把录入流水线跑通？

> 建议：**先丢 2~3 套 + 一份考试范围说明**给我，我把「扫描件 → 结构化试卷 → 校对 → 演练」这条链路先跑通并给你看效果，
> 确认没问题了你再批量灌剩下的。避免一次性灌 50 套之后发现格式要返工。
